# 🚀 Virtual Space Exploration: AR & VR  

Repo ini dibuat sebagai bahan pembelajaran **Augmented Reality (AR)** dan **Virtual Reality (VR)** menggunakan **A-Frame** dan **AR.js** dalam rangka __Ujian Akhir Semester__ mata kuliah **Augmented dan Virtual Reality**.  
Proyek ini mengangkat tema **Eksplorasi Luar Angkasa**, di mana pengguna dapat menjelajahi planet dalam **Augmented Reality (AR)** serta melakukan eksplorasi lingkungan **Virtual Reality (VR)** menggunakan A-Frame.  

🔗 **Repo GitHub**: [AR-VR](https://github.com/ceceprokani/AR-VR.git)

### 🔹 **Mode VR (Virtual Space Exploration)**  
1. Buka aplikasi melalui tautan berikut:  
   👉 [**Tautan Aplikasi VR**](https://ar-vr-git-uas-cecepfahriazal1997s-projects.vercel.app/)  
2. Gunakan **WASD** di keyboard atau **Joystick Virtual** di mobile untuk bergerak.  
3. Dekati planet yang ingin dieksplorasi.  
4. **Klik planet** untuk masuk ke dalam dunia planet tersebut.  
5. Gunakan tombol **"Kembali"** untuk kembali ke ruang angkasa utama.

## 🛠 Teknologi yang Digunakan  
- **AR.js** → Untuk Augmented Reality berbasis marker  
- **A-Frame (v1.6.0)** → Untuk eksplorasi Virtual Reality  
- **JavaScript (Vanilla JS)**  
- **HTML5 & CSS**  
- **Web Audio API** → Untuk efek suara latar  
- **LocalStorage** → Untuk menyimpan posisi kamera dalam eksplorasi VR  

---

## 🔹 Fitur Utama  
✅ **Mode AR:**  
- Marker-based AR dengan model 3D planet  
- Marker default: **Kanji, Hiro, Barcode**  

✅ **Mode VR:**  
- Navigasi menggunakan **WASD & Joystick Mobile**  
- **Klik planet** untuk masuk ke dunia eksplorasi  
- **Suara latar** otomatis saat halaman dimuat  
- **Penyimpanan posisi kamera** saat halaman di-reload  

---

## 📂 Struktur File  
📂 `/dist/` → Berisi A-Frame dan library tambahan.  
📂 `/js/components/` → Berisi komponen kustom seperti joystick & navigasi.  
📂 `/assets/` → Berisi gambar, audio, dan ikon aplikasi.  
📂 `/images/` → Thumbnail planet & latar belakang.  
📂 `/planets/` → Berisi dunia planet individu.  
📜 `index.html` → Halaman utama proyek.
